# AIsteria Aggregator

A WPF desktop application (.NET 6 / .NET 8) that sends a prompt to multiple AI providers simultaneously and displays all responses side-by-side, followed by a local synthesis generated by Ollama.

![.NET](https://img.shields.io/badge/.NET-6.0%20%2F%208.0-512BD4) ![Platform](https://img.shields.io/badge/platform-Windows-0078D4) ![License](https://img.shields.io/badge/license-non--commercial-blue)

---

## What it does

Type a prompt once — all enabled providers answer in parallel. Each answer appears as its own card with live status, response time and token usage, rendered as Markdown, with per-answer **Copy** and **Retry**. When all providers finish, a local Ollama instance generates a brief synthesis in the Summary box. Save whole sessions, reuse prompt templates, and export results to TXT / Markdown / HTML.

Image input is supported: load from file, paste, **drag-and-drop**, or **load from a URL** — several images per request. Vision-capable providers (OpenAI, Gemini, Groq, Mistral, OpenRouter, GitHub Models, NVIDIA, Claude, Ollama) receive the images alongside the text; others receive text only.

## Key features

- **Parallel execution** — all providers are queried via `Task.WhenAll()`; total wait time equals the slowest provider, not the sum
- **Per-provider result cards** — answers render **Markdown** (headings, lists, bold/italic, inline `code` and code blocks) and show live status, elapsed time and token usage, with per-card **Copy** and **Retry**; switch between **stacked** and **side-by-side** layout
- **Provider quick-toggle** — enable/disable any provider from the main window's *Providers* panel (no need to open Settings)
- **Model & parameters** — override the model per provider, and set global **temperature**, **max tokens** and an extra **system prompt** (Settings → Generation)
- **Answer language** — every request is instructed to reply in the user's language (falls back to English), so models like DeepSeek R1 don't switch to Chinese
- **Prompt templates & sessions** — save reusable prompts; save whole sessions (prompt + answers + summary) and search/reload them later
- **Export & copy** — save results as **TXT / Markdown / HTML**, or copy everything to the clipboard
- **Local synthesis** — Ollama aggregates all responses into a single coherent answer
- **Two input modes** — a **Text** tab for plain questions and an **Image** tab for an image plus an optional clarifying question; click the preview to open the picture full-size (in a window never larger than the main form)
- **Image support** — load from file, paste, **drag-and-drop**, or **load from URL**; **multiple images** per request; JPEG auto-resize to 1920 px before sending; click a preview to enlarge (Esc closes)
- **Encrypted API keys** — stored via Windows DPAPI (`ProtectedData.Protect`, `DataProtectionScope.CurrentUser`) in `%APPDATA%\Aisteria\settings.config`; keys are never written to disk in plain text
- **Question history** — up to 200 recent prompts saved to `%APPDATA%\Aisteria\history.txt`; duplicates are deduplicated and moved to top
- **Cancellation** — mid-request stop via a dedicated button; all in-flight HTTP calls are cancelled

## Architecture

All cloud providers that expose an OpenAI-compatible chat endpoint inherit from a shared `OpenAICompatibleProvider` base class. Google Gemini and Ollama have their own implementations due to differing API shapes. All providers implement a common `IAIProvider` interface, so adding a new one is a matter of implementing two methods and registering the instance.

```
IAIProvider
├── OpenAICompatibleProvider  (base)
│   ├── OpenAIProvider
│   ├── GroqProvider
│   ├── DeepSeekProvider
│   ├── MistralProvider
│   ├── OpenRouterProvider
│   ├── GitHubModelsProvider
│   ├── NvidiaProvider
│   ├── OllamaCloudProvider
│   └── PerplexityProvider
├── GeminiProvider
├── ClaudeProvider        (Anthropic Messages API)
└── OllamaProvider
```

## Setup

1. Clone the repo and open `AIsteriaAggregator.sln` in Visual Studio 2022.
2. Build and run (`F5`).
3. Open **Settings**, enter your API keys, and enable the providers you want.
4. Keys are encrypted and saved automatically — you only need to enter them once.

---

## Configuration

User settings and API keys are stored in `%APPDATA%\Aisteria\settings.config` — a per-user, user-writable location that survives rebuilds and works even when the app is installed under Program Files. API keys are Base64-encoded DPAPI ciphertext and are machine + user scoped — they cannot be reused on another machine or user account.

Default endpoint URLs ship in `App.config`; any value you change in Settings is written to `settings.config` and takes precedence. Base URLs can be overridden per provider, which makes it straightforward to point a provider at a local proxy or an alternative deployment.
